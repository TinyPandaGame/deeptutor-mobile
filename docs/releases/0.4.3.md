# 0.4.3

继续适配 DeepTutor 1.7.2，本次简化学习对话界面：

- 聊天底部默认显示输入框和“＋”，输入文字后显示“发送”。
- 点“＋”展开相册、拍照、文件、切换模型、学习方式；当前模型也放在面板内。
- 点回输入框切换到键盘，选择功能或按安卓返回键收起面板；保留草稿、附件预览及停止生成入口。
- 对话页标题保持一行，最多显示 12 个字符；首页、历史和单独追问列表最多显示 16 个字符，含省略号。完整标题仍可在“对话操作 → 查看或修改标题”中查看和编辑，原始标题和学习记录不改写。

126 项客户端功能测试、应用/测试类型检查、ESLint 及源码/历史隐私检查通过，详见[验证记录](../validation.md)。本次没有新增原生依赖；原生基础版本和构建号保持不变。

提供[完整 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.3/deeptutor-mobile-0.4.3-arm64-v8a.apk)及源码包。旧版可从“我的 → 应用更新”下载安装；首次使用需连接自己部署的 DeepTutor 服务。

安装包内置客户端版本 0.4.3，原生基础保持 0.4.1（versionCode 7），正式签名、运行时和包检查通过。本次未签发 OTA；没有启动 Android/iOS 设备或模拟器，未验收真实键盘、手势、视觉布局或安装。iOS 工程和 TestFlight 保持不变。
