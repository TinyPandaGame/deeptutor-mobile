# 0.4.1

继续适配 DeepTutor 1.7.2，并保留 1.7.1 的指定接口回归。本版为客户端修复，版本末位增加。

- 聊天、讲解、笔记等正文增加“复制全文”和“选择文字”。选择页将多段内容合成可连续选取的原生文字；复制常见公式时保留分组并转换乘除号、平方等符号，未知公式写法保留原义。
- 聊天照片、错题原图与受保护图片增加长按操作、复制图片和系统分享；复制的是图片数据，不是链接。受保护文件先走当前账号的授权下载，不向外部图片地址附加账号凭据。账号或内容切换会取消迟到的复制结果。
- 历史对话列表和聊天页菜单增加“删除对话”。二次确认明确包含单独追问；服务器确认后清理该对话的本机草稿并刷新列表。失败保留页面，重复点击不重复提交。
- 聊天菜单改为可滚动的原生操作面板，避免 Android 系统提醒框按钮数量限制隐藏操作。

提供[独立 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.1/deeptutor-mobile-0.4.1-arm64-v8a.apk)及源码包，也包含 0.4.0 的朗读、模型发现和批量导入功能。首次使用需连接自己部署的 DeepTutor 服务。

新增 Expo Clipboard 原生依赖，原生版本为 0.4.1、Android versionCode 7。安装包沿用原有正式签名；需要完整安装，不能把本版 JS 下发给缺少该模块的旧运行时。指纹和签名校验规则保持启用，本次没有发布 OTA。

完成功能/API 测试、构建、签名及包检查，范围见[验证记录](../validation.md)。未进行设备安装、长按手势、跨应用复制粘贴或分享验收。iOS 工程仍为 0.3.2，本次未构建 iOS 或上传 TestFlight。
