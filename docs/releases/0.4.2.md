# 0.4.2

继续适配 DeepTutor 1.7.2，本次修复客户端更新体验：

- 打开应用会检查本客户端 GitHub 发布版本。发现新版先弹窗，确认后再下载；需要完整 APK 的更新也会提醒。
- 选择“稍后”或关闭弹窗不下载，仍可进入“应用更新”查看新版并下载。同一次运行内同一更新只主动提醒一次，重新启动后可再次提醒。
- 更新页先显示新版和下载按钮，再显示当前版本，移除“自动更新”区域及预览版开关。
- 热更新下载完成后，由用户决定何时重启；下载失败可重试。完整包由系统安装，只有源码的发布不会显示虚假的下载按钮。
- 启动提示和更新页共享检查结果，保留同源发布、签名与运行时校验；确认只针对看到的版本，不会悄悄改为下载另一版。

提供[完整 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.2/deeptutor-mobile-0.4.2-arm64-v8a.apk)及源码包。旧版请先进入“我的 → 应用更新”下载安装；新提醒流程在安装 0.4.2 后生效。首次使用需连接自己部署的 DeepTutor 服务。

内置客户端版本为 0.4.2，原生基础仍为 0.4.1（versionCode 7），沿用原发行签名与运行时。本次没有 OTA，iOS 工程与 TestFlight 保持不变。

119 项客户端测试、构建与包检查通过，范围见[验证记录](../validation.md)。设备上的系统弹窗、浏览器安装和原生更新重启尚未验证。
