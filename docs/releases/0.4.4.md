# 0.4.4

继续适配 DeepTutor 1.7.2，保留 1.7.1 接口回归。

- 聊天文字和题目卡片平时只显示内容；长按展开复制、选取文字、朗读、单独追问、修改后再问及切换对话版本。图片保留点击放大、长按复制/分享。
- “提交答案”和“收进错题本”统一放在输入区“＋”面板。服务正在等待回答时仍能进入作答，提交被接受后才关闭，失败保留答案。
- 普通结构化练习通过官方判题接口识别明确的错误/部分正确结果并存入错题本；正确和未判定的不收录。判题使用该接口的服务端默认模型。精通学习复用服务端已保存的判题记录，不重复插入。重试使用稳定题目标识；普通聊天、仅上传但未经判题的照片不会被猜测为错题，仍可手动校对记录。
- 彻底删除聊天及多级单独追问，清理当前服务、账号、工作区内对应手机草稿、临时附件和已打开的聊天副本；阻止迟到下载或草稿回写恢复已删内容。
- 保留已收录错题的原编号、分类、作答记录和照片。服务端先独立保存照片并逐字节核对，再删除聊天数据库记录及附件；文件清理失败明确提示，并支持重试清理。

**服务端要求：**VPS 扩展本轮未部署。“保留错题的彻底删除”需管理员更新本仓库 `server/mobile_models` 包并重启服务后启用，入口仍是 `mobile_models.install(app)`。客户端升级不会自动部署扩展；未更新的服务器会阻止此项删除，详见[扩展说明](../../server/README.md)。

提供[完整 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.4/deeptutor-mobile-0.4.4-arm64-v8a.apk)及源码包。旧版可从“我的 → 应用更新”下载安装；首次使用需连接自己部署的 DeepTutor 服务。

143 项客户端测试、构建、签名和包检查通过，详见[验证记录](../validation.md)。内置客户端版本为 0.4.4，原生基础保持 0.4.1（versionCode 7），实际运行时与上一版一致。本次没有 OTA，iOS 工程及 TestFlight 不变；未进行设备手势、系统菜单/键盘、安装或真实模型判题实测。生产部署需单独验证。
