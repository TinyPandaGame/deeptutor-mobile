# 0.4.7

适配 DeepTutor 1.7.4。

- 学习首页新增“进行中”：查看当前账号、工作区的任务，在手机上接续、补答或停止；断线重连后恢复原任务。
- 对话支持按服务与模型能力选择推理强度，新对话默认继承工作区知识库。
- 阅读页新增测验、逐题原文提示和服务端判分，PDF 支持原页全屏查看。
- 教材支持章、节编辑及内容修改预览和撤销；精通学习题库支持搜索与分页。

提供[完整 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.7/deeptutor-mobile-0.4.7-arm64-v8a.apk)和源码包。首次使用需在电脑或服务器自行部署 DeepTutor 并保持在线。旧版可从“我的 → 应用更新”下载安装；0.4.2 起也会主动提示可用的完整 APK。

170 项客户端测试、类型检查、lint、源码与历史隐私检查通过。Android 构建和包检查通过，内置客户端版本为 0.4.7；沿用 0.4.1 原生基础、versionCode 7、既有签名与运行时。官方包接口回归及测试边界见[验证记录](../validation.md)。

本次仅发布源码和 Android APK，不提供 OTA；iOS、TestFlight 和服务器部署不变。未做本轮真机安装或新功能界面验收。
