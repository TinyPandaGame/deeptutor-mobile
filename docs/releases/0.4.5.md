# 0.4.5

继续适配 DeepTutor 1.7.2，保留 1.7.1 接口回归。

- 错题本新增“拍照 / 相册录入错题”入口；在记录页选图或拍照裁剪后，自动提取题干、选项和已有作答。
- 提取结果直接进入可编辑表单，标出不确定内容。识别只转录，不自动判错或生成标准答案；点击保存后才收进当前账号、工作区的错题本。
- 新照片不会直接覆盖已填内容；确认使用新题目后才替换，并清空上一道题的答案和讲解。失败、取消、选图权限拒绝都保留原内容，可重试或保留照片手动校对。
- 原图与校对后的文字一起保存。可查看这次识别记录，也可单独选择识图模型、进入模型与密钥管理；不更改聊天默认模型。

复用当前 DeepTutor 的模型列表、`/ws` 和错题保存接口，不增加 OCR SDK、原生依赖或新的服务器接口。需要服务端可用的图片输入模型；旧版没有能力声明时允许实际请求，明确不支持图片的模型会提示更换。照片经所连接的学习服务器交给已配置模型识别。

提供[完整 Android arm64 APK](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.4.5/deeptutor-mobile-0.4.5-arm64-v8a.apk)及源码包。旧版可从“我的 → 应用更新”下载安装；首次使用需连接自己部署的 DeepTutor 服务。

154 项客户端测试、类型检查、lint、构建及包检查通过，功能和接口验证见[验证记录](../validation.md)。内置客户端版本为 0.4.5，原生基础仍为 0.4.1（versionCode 7），签名与实际运行时和上一版一致。本次无 OTA，iOS 工程及 TestFlight 不变；无需新增服务端接口或部署。系统相机、相册裁剪、设备安装和真机视觉体验未重新验收。
