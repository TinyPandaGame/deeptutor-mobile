# DeepTutor 1.7.2 与客户端 0.4.0

核对官方 [v1.7.2 发布说明](https://github.com/HKUDS/DeepTutor/blob/v1.7.2/assets/releases/ver1-7-2.md)及 [1.7.1 → 1.7.2 差异](https://github.com/HKUDS/DeepTutor/compare/v1.7.1...v1.7.2)。目标 tag 提交为 `60fb3bdfddb30b7740c7ce3bd9b28d908f2af6db`。本次适配增加客户端次版本，源码为 **0.4.0**。

## 本次对应

| 官方变化 | 客户端处理与条件 |
| --- | --- |
| Chat、Mastery、Reading 选段朗读 | 聊天讲解、精通学习目标、阅读正文/笔记提供“选段朗读”。打开客户端自己的文字选择面板，长按选段或朗读全文；支持暂停、继续、停止和 0.75/1/1.25/1.5/2 倍速。速度按服务、账号、工作区、对话保存。取消、后台、退出账号时停止请求/播放并删除临时音频。不是嵌入官方网页或复制浏览器的选区工具栏。 |
| 语音接口与百分号/角度读法 | 使用当前服务器 `POST /api/voice/tts`，保留文本给官方语音清洗逻辑处理。服务必须安装启用 reading 模块并配置可用 TTS。缺模块、未配置、超时分别提示；普通账号使用共享语音配置，个人 LLM Key 不等于 TTS Key。 |
| 修改凭据后发现模型 | 服务商/个人模型表单延迟重新获取；配置变化立即作废旧请求结果。切换服务商或地址清除旧密钥输入，替换 Key 后不沿用先前发现的新选项。自定义服务商默认自动协议。 |
| 批量导入模型 | 管理员可按服务商与服务类型筛选、多选、手工补 ID。普通账号的个人模型同样可筛选和多选。共享配置逐个调用官方 registry API；失败不自动重放，重试先读取当前配置并跳过已保存项，保留已有默认模型和其他配置。 |
| 精通学习开始前选择模型 | 讨论路线、继续学习、复习和知识点入口均先选择模型，读取当前授权列表并在聊天草稿中传入实际 profile/model ID；发送前再次验证。删除或失去授权的模型不会被静默替换。 |
| 个人模型默认值修复 | 可选个人模型扩展重新验证 1.7.1 / 1.7.2，保留每账号隔离、密钥脱敏、稳定模型 ID 和下一次调用读取新 Key；未知版本仍拒绝加载。 |
| 取消与重试、精通学习上下文 | 官方 WS v2 请求契约未变；服务端取消确认改为等待释放任务所有权。客户端保留现有提交 ID、流式去重、取消确认、重连订阅和历史分支处理，不复制一套服务端评分或恢复逻辑。 |
| 检索、文档解析、只读笔记/收藏工具 | 属于服务端修复；客户端继续调用现有资料、知识库、笔记接口。仅更新客户端不能让旧服务器获得这些修复。 |
| NVIDIA NIM、DashScope、Responses/Codex | 服务端提供商兼容性修复；NIM 文本向量须明确选其 embedding binding，更换向量模型后重建索引。未逐家执行付费推理/图片生成，不宣称所有提供商均实测。 |
| 桌面安装、Windows、韩语、服务端自动升级 | 不移植桌面壳和系统安装逻辑，客户端仍为简体中文；客户端 GitHub 更新源仍为本仓库，不能直接下发官方后端版本。 |

## 验证与发行范围

新增功能使用客户端逻辑测试、实际官方 Python 包的 HTTP TestClient/配置合并测试验证。两个版本各运行独立临时 home，使用虚拟账号和模拟语音提供商；不启动本机学习后端，不访问生产学习资料，不消耗真实模型额度。

这次按维护者要求暂停本机 Android/iOS 运行测试。功能与接口测试通过后可同步 GitHub 源码；未验证系统文字选区手势、实体音频播放、相机分享、真实提供商推理，也未升级任何现有 VPS。具体结果见[验证记录](validation.md)。本次不生成新安装包、TestFlight 或 OTA 签名清单，既有下载仍使用各自已发布版本；源码发布不表示手机已经热更新。
