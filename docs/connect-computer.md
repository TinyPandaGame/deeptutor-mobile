# 连接自己的电脑

先按[安装说明](build.md)准备客户端。Android 发行 APK 不需要配置开发环境；iOS 工程需自行构建。这里的“电脑”是运行学习服务的主机，手机通过网络连接它。

以下以当前源码支持的 DeepTutor 1.7.2 为例；使用已有安装包或 iOS 工程时，请以对应 Release 标注的服务版本为准。

1. 在自己的电脑上按 [DeepTutor 1.7.2 官方说明](https://github.com/HKUDS/DeepTutor/tree/v1.7.2) 安装、配置并启动 DeepTutor。客户端不会替你启动电脑上的服务。
2. 让电脑和手机处于可互访的可信 Wi-Fi。电脑上的网页进程必须监听局域网接口，防火墙允许手机访问实际前端端口；访客 Wi-Fi 的设备隔离会阻止连接。电脑不要睡眠或断网。
3. 先在手机浏览器打开电脑的局域网首页，例如 `http://192.168.1.20:3782`。不要使用手机的 `localhost` / `127.0.0.1`。端口以你自己的部署为准，3782 仅为示例。
4. 首页、`/api/*` 和 `/ws` 必须同源可用。官方前端有 API 代理；若部署的 WebSocket 升级转发不能工作，使用反向代理，参照服务器接入示例。
5. App 选择“我的电脑”，填入该地址并点“下一步”。可直接输入 `192.168.1.20:3782`，私网地址自动补 `http://`；显式填写的 `https://` 不会降级。服务 `enabled=false` 时进入本机单用户空间；启用认证时用该服务的账号登录。

成功连接后，地址会出现在“已保存的服务”。下次打开自动恢复当前连接和登录；切换主机时选已有条目即可。移除服务会清除此设备为它保存的连接与登录，不会删除服务器上的学习资料。个人模型 Key 由所连接的服务器保存，见[个人模型扩展](../server/README.md)。

HTTP 不加密，只用于可信的局域网。免登录并不意味着可把服务裸露到公网；需要远程使用时选 VPN / 私有网络，或者部署 HTTPS 并启用认证。IPv4 私有网段、IPv6 ULA / 链路本地、`.local` 主机可以作为局域网入口；首版不支持公网 HTTP 或回环地址。仅启用 HTTPS 并不会自动给服务增加账号认证。

iOS 需允许“本地网络”权限；Android 通过原生配置允许动态局域网 HTTP，但客户端在发请求前限制为私有地址。ATS、本地网络和设备系统实际表现仍须分别验收，详见验证记录。

断线时先检查电脑在线、地址是否因 DHCP 改变、端口、访客网络和防火墙。地址改变后在“我的 → 管理或更换服务”添加新地址；新的源按独立服务处理，需要重新登录，不猜测是否同一台电脑。

模拟器的 `10.0.2.2` 是 Android 专用的宿主映射，仅用于开发测试。真实手机应使用电脑实际局域网 IP。
